# NexusHA Cloud Bridge

Port yönlendirme veya statik IP gerektirmeden Home Assistant sisteminizi **nexusha.app** bulut altyapısına güvenli şekilde bağlar.

## Kurulum ve Eşleştirme
1. Eklentiyi yükleyin ve **Başlat** butonuna basın.
2. Sol menüde beliren **NexusHA** sekmesine tıklayın (veya **Web Arayüzünü Aç** deyin).
3. Ekranda görünen **6 haneli eşleşme kodunu** (`NX-XXXX`) kopyalayın.
4. [nexusha.app](https://nexusha.app) hesabınıza giriş yaparak kodu girin.
